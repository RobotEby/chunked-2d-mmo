# chunked-2d-mmo

Nome técnico provisório de um projeto multiplayer 2D para desktop, com visão lateral, plataforma, gravidade e mundo organizado por chunks.

**Estágio atual:** fundação inicial, somente documentação. O projeto Unity ainda não foi inicializado; não há versão jogável.

A [baseline da fundação multiplayer](docs/architecture/multiplayer-foundation.md) registra as decisões aprovadas, o primeiro marco, os limites de escopo e os ADRs relacionados. Decisões aprovadas ainda dependem de implementação e validação prática.
